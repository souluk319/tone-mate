## Authority

- 무엇을 만들지는 제품 명세가 결정한다.
- 구현 가능한지와 어떤 수치로 판정할지는 기술검증 계획이 결정한다.
- 현재 시스템 경계는 루트 `DESIGN.md`가 설명한다.
- 요구사항과 결과 사이의 누락은 추적성 명세가 드러낸다.
- ChainShield E2E 문서는 완성된 제품 commit을 어떻게 검증할지만 결정하며 제품 요구사항을 추가하지 않는다.
- `docs/research/`는 근거와 가설을 제공하지만 규범적 요구사항을 직접 바꾸지 않는다.

충돌이 발견되면 문서 역할을 기준으로 분류하고, 의도된 변경이면 관련 명세·추적성·`DESIGN.md`·ADR을 같은 변경에서 갱신한다.

## Baseline provenance

초기 문서는 2026-09-02 별도 아이디어 작업 공간에서 작성되었다. 2026-09-04 ToneMate 저장소로 편입하면서 저장소·모듈·패키지 작업명을 `tonemate` 기준으로 정규화하고 내부 링크를 저장소 상대경로로 변경했다. 원본 아이디어 문서는 기존 위치에 보존되어 있다.

## Review rule

- 구현되지 않은 요구사항은 완료로 표시하지 않는다.
- 실험 전 알고리즘·threshold·지원 환경은 open decision으로 유지한다.
- 수치 변경은 결과를 본 뒤 소급 적용하지 않는다.
- 공개 패키지 좌표와 제품명은 첫 배포 전에 별도 검토한다.
